# Task-5
 I implemented both Decision Tree and Random Forest classifiers on the Heart Disease dataset using a clean, modular, function-based approach. The process began by loading and preparing the data, followed by training an unpruned and a pruned decision tree to observe the effect of depth on overfitting. The tree was visualized to better understand its structure. I then trained a Random Forest model and compared its performance to the decision tree. Key evaluation metrics like accuracy and classification reports were used, along with cross-validation to assess model stability. Finally, I visualized the feature importances from the Random Forest to interpret which variables most influenced predictions. This structure promotes code clarity and makes it easy to extend or reuse for other datasets.
